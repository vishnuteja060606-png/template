\# Project Blueprint Skill



Use this skill when:



\- starting a new project

\- defining architecture

\- changing project requirements

\- preparing hackathon architecture



\## Procedure



1\. Read the problem statement.

2\. Identify target users.

3\. Identify required features.

4\. Identify explicitly excluded features.

5\. Define technology stack.

6\. Define system architecture.

7\. Define frontend responsibilities.

8\. Define backend responsibilities.

9\. Define API boundaries.

10\. Define database model.

11\. Define security requirements.

12\. Define testing requirements.

13\. Define deployment strategy.

14\. Define demo flow.



Do not write application code.



Produce:



docs/PROJECT\_BLUEPRINT.md

docs/REQUIREMENTS.md

docs/ARCHITECTURE.md

docs/API\_CONTRACT.md

docs/DATABASE\_CONTRACT.md

docs/UI\_CONTRACT.md



Ask for approval before implementation begins.
