\# UI CONTRACT



\## Application Layout



App

├── Authentication

├── Dashboard

├── Feature A

├── Feature B

└── Profile



\## Screen States



Every screen must support:



1\. Loading

2\. Success

3\. Empty

4\. Error



\## Navigation



Authentication

→ Dashboard

→ Feature

→ Details



\## UI Standards



\- consistent spacing

\- reusable components

\- responsive layout

\- accessible controls

\- standard typography

\- standard error messages
